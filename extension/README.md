# HƯỚNG DẪN CÀI ĐẶT & SỬ DỤNG TIỆN ÍCH MỞ RỘNG (BROWSER EXTENSION) PATAWARE

Tiện ích mở rộng **PATAWARE Anti-Scam Shield** chạy trên chuẩn **Manifest V3**, tương thích với tất cả trình duyệt Chromium: **Google Chrome, Microsoft Edge, Cốc Cốc, Brave, Opera**.

---

## 🚀 3 Bước Cài Đặt Vào Trình Duyệt:

1. **Mở trang quản lý Tiện ích:**
   * **Chrome / Cốc Cốc / Brave:** Gõ vào thanh địa chỉ: `chrome://extensions/` (hoặc `coccoc://extensions/`)
   * **Microsoft Edge:** Gõ vào thanh địa chỉ: `edge://extensions/`

2. **Bật Chế độ Nhà phát triển (Developer mode):**
   * Gạt công tắc **"Developer mode"** (Chế độ cho nhà phát triển) ở góc trên bên phải sang **BẬT (ON)**.

3. **Tải tiện ích:**
   * Bấm nút **"Load unpacked"** (Tải tiện ích đã giải nén) ở góc trên bên trái.
   * Chọn đúng thư mục: `E:\PATAWARE\extension`
   * 🎉 Xong! Biểu tượng khiên an ninh PATAWARE sẽ xuất hiện trên thanh công cụ của trình duyệt.

---

## 🛡️ Cách Thử Nghiệm Tính Năng Chặn Lừa Đảo:

1. **Thử nghiệm trang web an toàn:**
   * Truy cập `google.com` hoặc `youtube.com` $\rightarrow$ Bấm vào biểu tượng PATAWARE trên thanh công cụ $\rightarrow$ Hiện nhãn **AN TOÀN** màu xanh.

2. **Thử nghiệm trang web lừa đảo (Tự động chặn & hiện Màn hình đỏ):**
   * Nhập vào thanh địa chỉ trình duyệt một link giả mạo ngân hàng, ví dụ:
     - `http://vietc0mbank-portal.xyz`
     - `http://sh0pee-vn.com`
     - `http://dang-nhap-otp-bank.xyz`
   * 👉 **Kết quả:** Trình duyệt lập tức bị chặn ngay trước khi tải trang, tự động chuyển hướng sang **Màn hình đỏ cảnh báo (Red Warning Screen)** của PATAWARE với đầy đủ thông số rủi ro, phân tích vi phạm và nút hành động an toàn!
